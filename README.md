# 公文 OCR 建檔工具

一個單一 HTML 檔案、雙擊即可開啟使用的公文掃描建檔工具。設計給地方政府機關的公文收發窗口使用：把公文 PDF 拖進來，就會自動 OCR 辨識、擷取發文者、受文者、發文字號、日期、主旨等欄位，整理成可搜尋、可篩選的清單。

> 範例資料裡的「米花市政府教育局」是虛構機關名稱（借用《名偵探柯南》裡的虛構城市），僅作為示範與測試之用，與任何真實機關無關。

## ⚠️ 這只是一個 PoC（概念驗證）

專案裡的公文範例都是假資料，OCR 的前處理、欄位擷取規則（`extractMetadata`、`parseFields` 等）也都是照著這批假資料的版面、用字習慣調校出來的。如果你把**真實**的公文 PDF 丟進來，版面格式、掃描品質、機關慣用語都可能跟樣本不一樣，辨識效果很可能不如預期，甚至完全抓不到欄位。

這個專案的目的是驗證「離線 OCR 建檔」這個做法可不可行，還不是一個能直接套用在任何機關、任何公文格式上的成品，要真的符合各單位的需求，需要針對實際公文樣式再繼續開發調整。

## 功能

### 匯入與辨識

- 拖曳或選擇多個公文 PDF，一次匯入、依序自動 OCR（PDF.js 渲染成圖片 → Tesseract.js 辨識，繁體中文 + 英文）。
- 辨識完成後自動擷取欄位：**文別**（令／呈／咨／函／公告／簽／書函／開會通知單／其他公文）、發文者、受文者、發文字號、發文日期、速別、密等、解密條件、附件、主旨、說明、擬辦。
- 相同檔名的檔案會被擋掉，不會重複匯入。

### 自動分類

- 依發文字號與機關全銜，自動判斷每份公文是**發文**（本機關發出）、**收文**（本機關收到）、**局內**（內部簽呈）還是未分類，並在清單上用色塊標示。

### 瀏覽、搜尋、篩選

- 清單可用關鍵字（檔名、字號、主旨、全文內容）即時搜尋。
- 可依發文者、受文者複選篩選；日期區間篩選（西元曆）。
- 日期欄位可點擊切換「近到遠 / 遠到近」排序。
- 每筆公文可點開詳細內容視窗，左邊直接預覽原始 PDF，右邊顯示所有擷取到的欄位與 OCR 全文。

### 內容校正

- 詳細內容視窗裡可以切到「校正內容」模式，逐欄手動修正 OCR 誤判的文字。
- 手動校正過的公文會標記起來，重新載入頁面時不會被自動覆蓋掉。

### 刪除與批次操作

- 每一列都可以單獨刪除（不會動到你電腦上的原始 PDF 檔案）。
- 表格每列也可勾選，表頭有全選／取消全選（含「部分已選」的中間態）。
- 勾選後會出現批次操作列：批次刪除、批次下載 Markdown（單筆直接下載 `.md`；多筆會在瀏覽器端用 JSZip 自動打包成 `.zip`，一份公文一個檔案）。

### 介面體驗

- 淺色介面，畫面往下捲動時標題列會自動收合，讓表格有更多顯示空間。
- 單一 HTML 檔案、零安裝：不需要 Node.js、不需要建置流程，複製檔案給任何人，雙擊開啟即可用。
- 除了首次載入需要網路（見下方「已知限制」），OCR、PDF 渲染、資料儲存都在本機瀏覽器裡完成，不會把公文內容送到任何伺服器。

## 使用方式

1. 下載 `公文OCR建檔工具.html`。
2. 雙擊開啟（或用任何瀏覽器開啟），**第一次使用需要網路**，用來從 CDN 載入 PDF.js、Tesseract.js、JSZip 以及中文 OCR 語言模型。之後視瀏覽器快取狀況，同一台電腦、同一個瀏覽器可能可以離線使用。
3. 把公文 PDF 拖曳到「匯入公文資料」視窗裡，或點擊選擇檔案，等待 OCR 辨識完成。
4. 在清單裡搜尋、篩選、查看詳細內容、手動校正欄位，或勾選多筆做批次刪除／匯出。

### 想先玩玩看再說？

`米花市公文範例/` 資料夾裡有 50 份虛構的示範公文 PDF（涵蓋函、簽、書函、開會通知單等不同文別），下載後直接拖進工具裡就能馬上體驗 OCR 建檔的效果，不用自己準備公文檔案。

## 已知限制

- **欄位擷取規則是針對範例假資料調校的**，換成真實公文效果可能落差很大，詳見上面「這只是一個 PoC」。
- 資料存在瀏覽器的 IndexedDB，綁定在「這台電腦＋這個瀏覽器」，不會跟著 `.html` 檔案本身移動；換瀏覽器或換電腦不會自動帶著走。
- 欄位擷取是規則式／啟發式解析（依 OCR 文字內容與行高判斷），遇到版面特殊或掃描品質不佳的公文可能需要手動校正。
- 第一次使用需要能連上網際網路（下載函式庫與 OCR 語言模型）；之後是否能完全離線視瀏覽器快取而定，目前沒有內建 Service Worker 做強制快取。

## 技術與致謝

- [PDF.js](https://mozilla.github.io/pdf.js/)（Mozilla）：PDF 渲染。
- [Tesseract.js](https://tesseract.projectnaptha.com/)：瀏覽器端 OCR 引擎（繁體中文 + 英文語言模型）。
- [JSZip](https://stuk.github.io/jszip/)：批次匯出時在瀏覽器端打包 `.zip`。
- 視覺設計參考並改寫自 monday.com 的 [Vibe Design System](https://vibe.monday.com)（顏色、字級、間距、圓角等 design token），純手刻 CSS 實作，並未使用 Vibe 的 React 元件庫或 npm 套件。
